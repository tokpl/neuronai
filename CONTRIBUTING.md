# Contributing

```bash
pnpm install
pnpm build
pnpm test
```

Published package: **`neuronai`** (`apps/cli`).

```bash
npx neuronai init
npm install -g neuronai
neuron init
```

## Rules

- Only changes that help Cursor understand a project
- No new enterprise / cloud features by default
- Conventional commits

## PRs

Run `pnpm lint && pnpm typecheck && pnpm test && pnpm build`.

See [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) and [SECURITY.md](./SECURITY.md).
