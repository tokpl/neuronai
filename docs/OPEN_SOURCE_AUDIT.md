# NeuronAI Open Source Audit

**Status:** Superseded for licensing guidance.

This document previously recommended a permissive open-core posture for public launch. The project has since migrated first-party code and package metadata to **AGPL-3.0**.

For the current license, rationale, consequences, and verification, see [`LICENSE_MIGRATION_REPORT.md`](./LICENSE_MIGRATION_REPORT.md) and the repository [`LICENSE`](../LICENSE).

Trademark policy (brand ≠ code license) remains in [`TRADEMARK.md`](../TRADEMARK.md). Community docs (`CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, GitHub templates) are unchanged in purpose; inbound contributions are under AGPL-3.0 with no CLA.
