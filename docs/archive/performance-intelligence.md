# Performance Intelligence

Neuron helps build scalable systems by combining **architectural context**, **incident history**, and **heuristic performance analysis**.

It does **not** replace profilers or APM. No production monitoring. No auto-deploy of optimizations.

Package: `@neuron-ai-memory/performance-intelligence`  
Persistence: `.neuron/performance.json`, `.neuron/performance-report.md`

See [scalability.md](./scalability.md) and [performance-review.md](./performance-review.md).
