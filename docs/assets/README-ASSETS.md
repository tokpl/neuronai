# README landing assets

Rich dark continuous PNG set for the product README (not SVG, not ultra-minimal).

## Style

- Canvas: GitHub dark `#0d1117`
- Accent: teal / cyan glass panels + soft neural atmosphere
- Brand word **NeuronAI** only on `hero.png` (+ markdown logo)
- One typography / spacing language across the scroll
- Benefit copy: adapt agent to the project, explain once, remembered
