# 04 — Memory review

## Goal

Show Save | Edit | Ignore / explicit save after an outcome.

## Prep

Finish a small decision in chat, e.g. “Use Stripe Checkout for card payments.”

## Steps (record)

1. User:

   > We decided to use Stripe Checkout for card payments. Review and save with Neuron.

2. Tools: `neuron_review_memory` then `neuron_save_decision` (or `neuron_after_task`).
3. Terminal:
   ```bash
   neuron search "Stripe"
   ```
4. Open `.neuron/decisions.md` — new section visible.

## Narration

> “Knowledge compounds. Next session already knows Stripe Checkout.”

## Privacy note (on-screen text)

Suggest mode by default — Neuron proposes; you confirm.
