# Good first issues

Suggested starter tasks for contributors:

1. Improve TypeScriptAnalyzer import resolution edge cases
2. Add more fixtures to CLI `neuron doctor` checks
3. Expand FAQ with real Cursor setup screenshots (text-only first)
4. `neuron maintain --apply` to archive duplicate candidates
5. Markdown export polish for decisions vs patterns

Label issues with `good first issue` on the tracker when filing.

See [CONTRIBUTING.md](../CONTRIBUTING.md) and [docs/architecture-guide.md](../docs/architecture-guide.md).
