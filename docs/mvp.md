# MVP scope (v0.1 Local Project Brain)

Neuron = **AI that understands your project** (local Cursor memory).  
Not = AI that does everything.

## In scope (P0)

1. Install CLI + MCP  
2. `neuron init` / `neuron scan` → project brain  
3. Local memory storage (decisions, patterns, warnings)  
4. Knowledge graph seeds from scan  
5. Retrieval with context budget  
6. Cursor rules/skills/commands  
7. Basic prepare / search / save decision  
8. Privacy: local-only, telemetry off, redaction  

## Out of scope for MVP

- Cloud SaaS, billing, marketplace  
- Autonomous multi-agent coding  
- Auto mass-refactor  
- Enterprise IAM / org workspaces as “ready”  
- APM / antivirus / git hosting replacement  

## After MVP (ordered)

**P1:** architecture, docs, git history, resume, security sanitize, explain-last  
**P2:** team brain, performance, evaluation, governance  
**P3:** enterprise deploy, optional cloud sync (premium candidate)

See [product-architecture-review.md](./product-architecture-review.md) for full matrix and checklist.
