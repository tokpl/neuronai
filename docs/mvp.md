# MVP scope

Neuron = **AI memory that understands your project** (local, Cursor).

## In scope

1. `npm i -g neuron` + `neuron init`
2. Local `.neuron/` FileStorageProvider
3. Project scan → brain bootstrap
4. Budgeted retrieval via MCP
5. Save / search / update decisions & knowledge
6. Cursor rules + skills for the 12 tools
7. Privacy: local-only, telemetry off
8. Git as Team Brain

## Out of scope

- Cloud SaaS, billing, marketplace
- Autonomous coding agents
- Enterprise IAM / multi-tenant workspaces
- Requiring Docker / Postgres / API keys
